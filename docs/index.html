로그인 가드 테스터를 찾습니다

무차별 대입 공격을 막는 작은 WordPress 보안 플러그인을 만들었어요. 여러분의 솔직한 피드백으로 더 좋게 다듬고 싶습니다. 🙏

✍️ 피드백 남기기 ⬇️ 플러그인 받기

안녕하세요! 컴퓨터 전공 학생입니다. 학교 오픈소스/DevOps 과제로 직접 만든 플러그인을 실제로 써보신 분들의 피드백을 받아 1~2주마다 개선하는 프로젝트를 진행하고 있어요. 염치없지만… 딱 5분만 도와주시면 정말 감사하겠습니다. 납작 엎드려 부탁드립니다 🙇

🎁 참여 선물

피드백을 남겨주신 분들 중 추첨으로 3분께 커피 기프티콘(5,000원)을 보내드립니다. (국내 기프티콘 발송 관계로 한국에서 받으실 수 있는 분 대상이에요.)

🧩 어떤 플러그인인가요?

  • 로그인 비밀번호를 여러 번 틀리면(기본 5회) 그 접속을 일정 시간 잠가 무차별 대입 공격을 막습니다.
  • 허용 횟수·잠금 시간을 직접 설정할 수 있고, 보안 로그로 차단 내역을 봅니다.
  • 삭제하면 데이터도 깨끗이 정리됩니다.

✅ 이렇게 해보시면 돼요

1
플러그인 받기 → 관리자 → 플러그인 → 새로 추가 → 업로드 → 활성화
2
로그아웃 후 로그인 창에서 일부러 비밀번호를 5번 이상 틀려 보기
3
“로그인 차단” 메시지가 뜨면 성공! 관리자 「로그인 가드」에서 보안 로그도 구경
4
피드백 폼에 “좋았던 점”과 “더 필요한 점”을 각각 한 줄 이상 남겨주기
⚠️ 학생이 만든 프로젝트라 완벽하지 않을 수 있어요. 중요한 운영 사이트보다 테스트/개인 사이트에 설치해 주세요. 혹시 문제가 생기면 플러그인을 비활성화·삭제하면 원래대로 돌아갑니다.

✍️ 피드백은 이렇게

  1. 👍 좋았던 점 — 한 줄 이상
  2. 🛠 더 필요하거나 아쉬운 점 — 한 줄 이상
  3. 🖥 어떤 환경에서 써보셨는지(사이트 종류 등)
  4. 📸 설치/동작 화면 스크린샷 1장 (실제 사용 인증용)
  5. 📮 추첨용 이메일 (선택)
