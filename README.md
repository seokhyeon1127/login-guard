# 🛡 로그인 가드 (Login Guard)

WordPress 로그인 창을 노리는 **무차별 대입(brute-force) 공격**을 막아주는 가벼운 보안 플러그인입니다.
지정한 횟수(기본 5회) 이상 연속 로그인 실패 시, 해당 IP의 로그인을 일정 시간(기본 10분) 차단합니다.

> 🎓 이 저장소는 대학 **오픈소스/DevOps 과제**로 진행되는 학생 프로젝트입니다.
> 실제 사용자 여러분의 피드백을 받아 **1~2주마다 버전을 개선**하며 운영합니다.
> **[👉 참여하고 피드백 남기기](https://seokhyeon1127.github.io/login-guard/)** (추첨을 통해 커피 기프티콘 증정!)

## ✨ 기능 (v1.0.0)
- 로그인 실패 횟수 제한 → 임계치 초과 시 IP 자동 잠금
- 허용 실패 횟수 / 잠금 시간 설정
- 로그인 실패·잠금·차단 이벤트 **보안 로그**
- 삭제 시 옵션·로그 테이블 자동 정리(흔적 없음)

## 📥 설치
1. [Releases](https://github.com/seokhyeon1127/login-guard/releases)에서 최신 `login-guard-x.y.z.zip` 다운로드
2. WordPress 관리자 → **플러그인 → 새로 추가 → 플러그인 업로드** → zip 업로드 → 활성화
3. 왼쪽 메뉴 **「로그인 가드」**에서 설정

> ⚠️ 학생 프로젝트(무보증)입니다. **가급적 테스트/개인 사이트**에 설치해 주세요.

## 🧪 테스트 방법 (피드백용)
1. 설정에서 허용 실패 횟수를 확인(기본 5회)
2. 로그아웃 후 로그인 창에서 **일부러 틀린 비밀번호를 5회 이상** 입력
3. "로그인 차단" 메시지가 뜨면 정상 동작 ✅
4. 관리자 「로그인 가드」 → 보안 로그에서 기록 확인
